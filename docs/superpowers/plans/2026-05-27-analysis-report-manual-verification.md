# 분석 보고서 변경 — 수동 검증 시나리오 (issue #82)

PR 머지 전 수동으로 확인할 항목:

## 시나리오 1: 활성 평가기준 2개 + 신규 분석

1. 관리자 계정으로 평가기준 2개 활성화 (관리자 패널에서 토글 ON)
2. 사용자 계정으로 로그인 → 수업지도안 PDF 업로드
3. 분석 실행
4. 생성된 보고서 확인:
   - 보고서 헤더 블록 (`> **분석 개요**` 다음)에 `**분석 모델**: ...` 줄이 **없어야** 한다
   - `### File Search 참고 문서` 섹션의 항목이:
     * 활성 평가기준 2개의 표시 이름 (관리자 패널에 표시되는 alias)
     * 업로드한 수업지도안의 원본 파일명 (예: `수업안.pdf`)
     으로 총 3개 항목이어야 한다

## 시나리오 2: 평가기준 토글 OFF 후 재분석

1. 시나리오 1 직후, 평가기준 1개를 OFF 토글
2. 다른 수업지도안 업로드 → 새 분석 실행
3. 새 보고서의 `### File Search 참고 문서` 섹션에:
   - OFF 토글한 평가기준 alias는 사라져야 한다
   - 남은 활성 평가기준 1개 + 새 수업지도안 파일명만 표시

## 시나리오 3: 모든 평가기준 OFF

1. 모든 평가기준을 OFF로 토글
2. 분석 시도
3. Expected: `NO_ACTIVE_CRITERIA` 에러로 분석이 조기 종료되어야 한다 (보고서 자체가 생성되지 않음)

## 시나리오 4: 과거 보고서 영향 없음

1. issue #82 머지 전에 생성된 과거 보고서를 조회/다운로드
2. 보고서 내용이 변경되지 않고 그대로여야 한다 (디스크 파일 마이그레이션 없음)
